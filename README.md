# Syracuse Web Design Co.

Marketing site for **Syracuse Web Design Co.** — done-for-you websites for Syracuse, NY small businesses. Founder: Harun Mohamed.

## Local preview

```bash
cd /workspace/swd-site
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

Or open `index.html` directly in a browser (fonts need network for Google Fonts).
